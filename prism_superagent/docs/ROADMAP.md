# Roadmap

## Current foundation
Provider abstraction, router, tools, workspace, memory, planner, verifier, Flask UI.

## Next
1. Structured tool calling in every provider.
2. Tool-result continuation loop.
3. Patch-based code editing.
4. Automatic test/fix cycles.
5. Better web source/citation layer.
6. Excel/Pandas/PDF/OCR tools.
7. PostgreSQL/Supabase memory.
8. Playwright browser agent.
9. FFmpeg/media tools.
10. Docker/CUDA build tools.
11. Project/task queue and observability.
12. Authentication, sandboxing and approvals.
13. Specialist agents such as Researcher, Coder, Data Analyst and Reviewer.
