# Model routing

Prefer deterministic tools for deterministic work.

- arithmetic/data -> Python/Pandas
- database facts -> SQL
- current facts -> web/API
- code -> model + filesystem + terminal + tests
- video -> FFmpeg
- GPU -> CUDA/toolchain
- simple/private tasks -> Ollama
- difficult reasoning/coding -> configured cloud model

This can reduce unnecessary cloud calls without pretending that tools replace
the reasoning capability of a strong model.
