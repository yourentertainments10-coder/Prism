# Example workflows

## Coding
Inspect -> edit -> run tests -> read traceback -> fix -> test -> verify.

## Research
Detect whether information is current -> use official API/structured source where possible
-> search -> extract -> cross-check -> cite source/date.

## Data analysis
Inspect Excel/CSV -> Pandas -> calculations -> charts -> explanation.

## C++/CUDA
Inspect compiler/toolchain -> write code -> build -> execute -> benchmark -> fix -> report.

## Video
Inspect clips/audio -> Python/FFmpeg processing -> render -> validate output -> report.
